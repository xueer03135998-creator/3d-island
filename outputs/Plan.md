# 海岛作品集 第六轮升级方案

## 背景

现有海岛已能漫游、进馆、触发彩蛋。本轮要把它从"能看"升级为"能玩、讲得清"：

- 每个场馆除了体验本身，还要讲清产品是什么、有什么价值、用户怎么走完一条链路。
- 个人档案馆不再带产品岗位导向，面向所有岗位的访客。
- 场景更有生命力：开门入馆、划船、坐下休息、日夜切换、流星、远山、猫狗。
- 以上全部在手机上同样可用。

做成后：访客走到馆门口，门打开，弹出场馆界面；每个界面里可以在"体验"和"项目介绍"之间切换。

## 做法

### A. 场馆内容

1. 非遗体验馆小字改为"非遗互动小故事"（`three/buildings/index.ts` 的 `SPECS` 副标题，同步 `data/buildings.ts`）。
2. 易经占卜馆、食堂小屋、非遗体验馆打开后，顶部出现两个标签："体验"（现有嵌入页）和"项目介绍"。
   - 项目介绍分三块：产品是什么与价值、主要功能、链路设计（步骤条，从进入到完成）。
   - 内容集中在新文件 `data/projectIntro.ts`，新组件 `components/ProjectIntro.tsx`，由 `BuildingPanel.tsx` 接入。
   - 易经占卜馆、非遗体验馆的内容来自已读到的页面；食堂小屋的页面只能确认"午饭选择工具、菜品与评价、手绘风"，链路按此保守撰写，交付时说明。
3. 个人档案馆：
   - 基本信息删除"数据产品 · 商业化产品 · AI Agent 产品"一行（`RESUME_PROFILE.headline`），改为中性的一句自我定位，不含具体岗位。
   - 馆标签由 `['简历','数据产品','AI Agent']` 改为 `['个人档案','实习经历','技能荣誉']`。
   - `data/resumeQa.ts` 中带投递产品岗位倾向的回答改为中性表述，覆盖"想做什么方向"类问题。
   - 实习经历里的业务领域、岗位方向标签保留，只作为每段经历的事实记录。

### B. 进馆开门

- 人物走到门口范围（`doorPoint` 约 1.6 以内）且正朝门走时，自动触发：
  1. 人物停下，门扇向内打开（约 0.6 秒）；
  2. 人物迈入，淡出；
  3. 弹出场馆界面。
- 门扇需要独立网格（建筑是合并网格），在各馆 `buildings/*.ts` 门洞处加一个可旋转的门扇组，放入 `BuildingEntry.door`。
- 点击建筑、按 E、手机"进入"按钮仍可进馆，走同一个开门流程（`world.ts` 的 `select`，替换原先 0.38 秒的挤压效果为开门动作）。
- 关闭界面后门关上，人物回到门外一步；需离开门口 5 个单位以上才会再次自动触发，避免反复弹出。

### C. 划船与坐下

- 划船：靠近码头小船（`nature.ts` 的 `rowboat`）时 Hud 出现"上船"，点击小船也可上船。上船后人物坐在船里，摇杆或 WASD 控制划行，桨有划动动画；只能在 `withinSwimArea` 内行驶，碰到岸边或码头减速停下。Hud 出现"下船"，在岸边、码头附近才能下船，否则提示"靠岸后再下船"。
- 坐下：点击石头、椅子，人物走过去坐下，姿态切换为坐姿；有输入移动即站起。
  - 石头：坐下时周围飘起几片小星光。
  - 椅子：椅子轻轻摇一下，飘出音符。
- 座位数据集中在新文件 `three/seats.ts`（位置、朝向、高度、拾取对象），由 `controls.ts` 拾取，`character.ts` 增加 `sit/stand/boat` 状态。

### D. 彩蛋与时间切换

- 树木彩蛋：点击树冠后，从树冠位置落下一阵叶子，叶子向下飘落、轻微左右摆动，落到地面后淡出（`interactions.ts` 的 `play('nature')`，复用 `Effects.burst` 并把重力调为向下）。
- 中央圆盘（`plaza` 彩蛋）不再放烟花，改为切换时间，三档循环：
  1. 白天 → 点一下：落日时刻（暖橙天空、长影子）；
  2. 落日 → 再点一下：星空夜晚，伴随流星隔几秒从天空滑过；
  3. 夜晚 → 再点一下：回到白天。
- 切换用约 3 秒平滑过渡（`environment.ts` 新增 `setPhase(phase)`，沿用 `envKeys.ts` 的 `sampleFrame` 插值）；过渡中再次点击忽略，避免来回抖动。
- 流星：`sky.ts` 新增流星层（几条带拖尾的亮线，随机方向、0.8 秒内滑过），只在夜晚相位出现。
- 五个彩蛋集齐出彩虹的规则不变，圆盘彩蛋仍然计入。

### E. 画面与生气

- 视野：拖动视角的俯仰下限从 0.12 放宽到约 -0.3（可平视并仰望天空），相机地面保护线保持不变；手机竖屏保留现有 FOV 自适应。
- 缩放：Hud 右侧新增"放大 / 缩小"两个按钮，键盘 `+ / -` 也可用；范围 4–36，滚轮与双指缩放继续可用，四者共用同一个 `distGoal`（`controls.ts` 新增 `zoomBy(step)`，`world.ts` 暴露，`Hud.tsx` 接入）。
- 远山：`createMountains()`（`environment.ts`）由两圈单色圆锥，改为三层山脊。
  - 用带噪声起伏的山脊网格，山顶高低错落。
  - 顶点着色：山脚到山顶渐变，高处浅色。
  - 越远越淡，融入雾色，近层偏绿，远层偏蓝紫。
- 猫狗：新文件 `three/pets.ts`，2 只小猫、2 只小狗，沿用 `life.ts` 蝴蝶的 `Fx` 模式。
  - 行为：在草地上闲逛，互相追逐，偶尔扑球玩耍，人物靠近时跑过来绕圈。
  - 约束：不进水，不穿过房屋和树木碰撞体（读 `colliders`）。
  - 点击宠物会蹦一下并飘出爱心；数量固定，不随时间增长。
- 主角不背书包：删除 `character.ts` 里的 `PACK` 颜色和书包那一行盒体。

### F. 手机适配

- 开门入馆、上下船、坐下、缩放、圆盘切换全部可用触屏完成。
- 摇杆移动时自动取消坐下；上船后摇杆用于划船。
- Hud 在手机上上下船、进入、缩放按钮不遮挡摇杆和跑步键，触控面积不小于 40px。
- 项目介绍页在窄屏上单列排列，步骤条纵向展示，不出现横向滚动。

### 不做

- 不改三个嵌入项目本身（占卜、食堂、非遗页面保持原样）。
- 不增加后端、登录、数据存储。
- 不做天气切换，天气仍固定为晴。
- 不做多人联机或更多宠物种类。

## 验收

### 主流程

1. 非遗体验馆屋顶小字显示"非遗互动小故事"。
2. 三个项目馆都有"体验 / 项目介绍"两个标签，项目介绍含价值、功能、链路三块；档案馆保持原三个标签。
3. 档案馆基本信息、馆标签、提问回答中不再出现"数据产品 / 商业化产品 / AI Agent 产品"这一行定位，也没有"为投递产品岗位"的表述。
4. 走到任意馆门口：门打开 → 人物进入 → 界面弹出；点击建筑、按 E、手机按钮走同一流程。
5. 能上船、划船、下船；能坐石头和椅子，点击有小互动。
6. 点树掉叶；点圆盘按"落日 → 夜晚（有流星）→ 白天"循环，无烟花。
7. 能仰望天空；放大缩小按钮、滚轮、双指均有效。
8. 远山有起伏和层次；场景里有 2 猫 2 狗在玩耍；主角无书包。

### 边界与异常

- 防重复：开门过程中再次点击或走动不会重复弹出；关闭界面后需离开门口才会再次自动进入；圆盘在过渡中的点击被忽略；连续点击坐下、上船不会叠加动作。
- 界面打开时（`setPaused`）：人物不可操作，上下船、缩放、坐下输入无效；关闭后恢复。
- 划船：不能驶出游泳范围，不会穿过码头和岸边；离岸太远时"下船"给出"靠岸后再下船"的提示，不会把人放进岩石或房屋里。
- 坐下：被碰撞体挡住的座位不会让人物穿模；起身后位置在可行走区域内。
- 宠物：不进水、不穿房屋和树；多只宠物不重叠成一团。
- 缩放与视角：缩放有上下限，仰角有下限，相机不会钻进地面或穿过水面以下看到空洞。
- 项目介绍：内容为空时显示"暂无介绍"空态；嵌入页加载失败时保留现有的失败提示，并仍可切到项目介绍。
- WebGL 不可用时沿用现有降级提示，不白屏。
- 桌面与手机（390 宽）都截图检查：岛屿全景、项目介绍、档案基本信息、落日、夜晚流星、仰望天空、划船、坐下。
- 验证命令：`pnpm run typecheck`、`pnpm run build` 均通过；无遗留调试代码和临时文件。

### 按默认处理的事项

- 开门由走到门口自动触发，同时保留点击和 E 键。
- 食堂小屋的项目介绍基于页面可见内容保守撰写，上线后可再补细节。
- 时间切换为白天 → 落日 → 夜晚 → 白天循环。
