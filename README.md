# 请雇我工作岛 · 3D 作品集

一个可以走进去的个人作品集。访客操控角色在岛上漫游，四座展馆对应个人档案和三个项目，走到门口会自动开门，也可以点击建筑直接打开。名字有点自嘲，也有点认真，我确实在找工作，希望你看完作品之后愿意聊聊。

在线体验：https://xueer03135998-creator.github.io/3d-island/

## 四座展馆

个人档案馆放基本信息、实习经历、技能和荣誉，分栏查看。馆门口有长椅，可以坐下来看。

易经占卜馆对应梅花易数与小六壬的网页，数字起卦后生成本卦、互卦、变卦和一份白话报告，能回看历史、导出分享卡片。这里嵌的是占卜项目的独立页面。

食堂小屋对应午餐助手，按人数、预算、等待时间、口味和忌口从内置餐品里挑一个，可以收藏、放进备选、换一个。嵌的是午餐助手的独立页面。

非遗体验馆是互动故事《木偶·归途》，跟着剧情一步步走完，手机竖屏体验更好。这个页面随站点一起发布，不依赖外部链接。

每座展馆打开后都有体验与项目介绍两个标签。项目介绍讲产品是什么、主要功能，以及用户怎么走完一条链路。

## 岛上的走法

电脑用 WASD 或方向键移动，Shift 奔跑，空格跳跃，拖拽或 Q / R 旋转视角，滚轮或加减号缩放。点击地面会自动走过去，点击建筑打开介绍。走到馆门前会自动开门，人物进去后弹出界面。

手机用左下摇杆移动，按住奔跑，右下跳跃，双指拖动平移视野、捏合缩放。右上角是声音键和向导提问入口。

除了四座展馆，岛上还有几件可以玩的事。档案馆门口的长椅和食堂门口的圆凳都能坐，点一下走过去坐下，有移动输入就站起来。码头边有小船，可以上船在限定水域里划。树、小船、主角、广场圆盘和海面各有一个彩蛋，集齐五个会出彩虹；点广场圆盘还能在白天、落日和夜晚之间切换。

## 向导与提问

岛上的向导是乌空兔。走近它按 E 或点对话按钮就能聊，可以问怎么玩、听它介绍各个馆，介绍里的场馆卡片点一下直接进馆。从卡片进馆后退出，会回到刚才那段对话，不会从头开始。

提问面板里是预置的问答，围绕个人背景、实习经历和三个项目展开。点开后选问题看回答，不需要输入，也不请求后端。面板可以收起。

## 仓库里有什么

main 分支是源码，`frontend/` 下是一个 React + TypeScript 项目，用 Vite 构建，3D 部分基于 three.js，界面用了 React Router 和 Tailwind CSS。`src/three/` 放场景、建筑、角色、坐椅、划船、交互和寻路，`src/components/` 放 HUD、NPC 对话、场馆面板和提问面板，`src/data/` 放展馆信息、简历内容和问答数据，`public/` 下是非遗页面和兔子模型。`outputs/Plan.md` 是早期规划，留作背景参考。

gh-pages 分支只放构建后的静态文件。GitHub Pages 从这个分支根目录发布，更新产物后链接不变。

## 本地运行

需要 Node 22 以上。在 `frontend/` 里安装依赖后启动开发服务，默认端口 8070。

```
pnpm install
pnpm dev
```

构建产物要按部署路径设置 base，项目站点的路径是 `/3d-island/`。仓库里的 `.env.production` 默认是 `/`，部署时用 `.env.production.local` 覆盖为 `/3d-island/`，这个本地文件不要提交。它同时决定 Vite 的资源前缀和 React Router 的 basename，写错会让页面落到应用内的 404。

## 数据

没有后端，也没有账号。简历、问答和展馆信息都写在源码里，页面不采集数据。嵌入的占卜馆和午餐助手是另外两个静态页面，数据规则见各自仓库。
